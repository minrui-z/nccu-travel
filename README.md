# 政大差旅報帳工作台

桌面版國外出差旅費填表工具。以 115 年版檢查表為依據，支援一般版與學生版，在瀏覽器完成填寫、試算、原表預覽與原生 XLS 下載。

[開啟網站](https://minrui-z.github.io/nccu-travel/) · [查看填寫範例](https://minrui-z.github.io/nccu-travel/?example=general)

**這個資料夾就是可公開的專案根目錄。** 發布 `website` 的內容即可；上層的已填範例、私人報帳資料不要加入儲存庫。

## 開始使用

需要 Node.js 22.13 以上；建議 Node.js 24。

```sh
npm ci
npm run dev
```

開啟顯示的本機網址。初次為空白報帳表，可從「更多操作 → 查看填寫範例」另開唯讀頁面，切換一般版及學生版；範例不讀寫草稿，也不提供編輯或下載。姓名、費用與行程保存在目前瀏覽器的 IndexedDB，重新整理後會恢復。無登入、資料庫、Java 服務或填表 API。網站僅讀取同站的字型、空白模板及官方資料，不上傳報帳內容。

填寫順序：

1. **基本資料**：選一般／學生版，填姓名、出差事由及經費資料；有核定上限時填入金額。
2. **行程與生活費**：輸入當地出發與返國日期，按「建立行程」；修改日期後按「套用日期」才更新行程。地點先選國家、再選城市；交通工具歇夜及返國日分別填起點、迄點，另選日支額適用地區。需要合併時進入「合併日期」，選相同且連續的日期。已合併欄位一起修改，明確拆開才分開；兩版均可使用 1–12 欄，主表維持 A4 單頁。
3. **費用**：新增時先選費類，再填單筆內容。清單顯示日期、幣別、金額及待補資料，一次展開一筆；保險、艙等與適用核准欄位隨費類顯示。各筆外幣匯率獨立，成功帶入後顯示匯率、日期及來源，可展開修改；單據號數選填。
4. **檢查與下載**：核對計算、附件及原表預覽；需修正項目可直接前往對應欄位。按「下載報帳表」取得原生 XLS。附件總張數尚未整理時可留白，列印後補填；正式送件前完成簽章與附件。

各步驟可自由切換，已填內容保留。縮短日期會先列出移除的行程及受影響費用，取消不改資料；確認後保留全部費用，請重新核對超出範圍的列入日期。「重新填寫」會先備份目前草稿，成功後才建立空白表；可由「更多操作 → 恢復上一份草稿」復原，重新整理後仍可使用。只保留上一份，並非多版本歷史；保存失敗時保留目前內容並提供重試。

選「私人行程，不請領」後，工作記要固定填入「個人行程」，地點可選填；合併欄內各日同步修改。日支額、膳宿、扣款及請領費用欄保持空白。切回出差日保留地點，但須重新填寫工作記要與日支額。變更幣別、匯率來源或適用日期時會清除不再適用的匯率與證明；更改行程日期後須重新核對保費上限。

## 計算方式與範圍

- 尾數計算：同類費用按各筆匯率精確加總後，四捨五入至臺幣元，再合計各類。匿名算例重現 77,759 元，本次申請上限 70,000 元。範例的匯率、日支額與保費上限只用於測試，不是對應日期的實際標準。
- 日期合併：符合條件才可合併，總額不變；官方要求逐日列支，是否接受合併仍需主計室確認。
- 依本工具的使用需求，例假日與公差申請狀態不作為填表或支領資格門檻；明確標記為私人行程的日期仍不列支。這是工具設定，不代表官方規則已取消相關要求。
- 銀行匯率仍依報價日處理；「匯率基準出發日」只決定匯率與結匯證明日期，不限制行程日期。特定經費、行政費及艙等的核准條件另行保留。
- 計算口徑的來源與適用限制見 [資料說明](docs/DATA.md)。
- 銷差後 45 日顯示為送件提醒；起算、假日順延及特殊個案請依主計室核定。

學生案件請在「本案核定補助上限」填核定金額；超額處理與來源見 [學生補助說明](docs/STUDENT-FUNDING.md)。

隨網站提供 2025-01-02 至 2026-09-08 共 414 個報價日、19 種幣別的臺銀匯率資料。資料按實際報價日保存，不把未報價日或缺漏日期當作已有資料；仍可匯入官方檔案或輸入有依據的匯率。資料範圍及更新方式見 [資料說明](docs/DATA.md)。

## 發布到 GitHub Pages

1. 建立自己的 GitHub 儲存庫，把本資料夾**內的內容**放在儲存庫根目錄，預設分支用 `main`。
2. 在 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
3. 在 **Actions** 執行 **Build and publish GitHub Pages**，或推送到 `main`。工作流程先測試，再建置並部署 `dist`。
4. 完成後 Pages 會顯示 `https://帳號.github.io/專案名稱/`。Vite 使用相對路徑，模板、資料及 Worker 都支援專案子路徑。
5. 啟用每日資料更新需允許內建 `GITHUB_TOKEN` 對內容寫入；受分支保護限制時，可停用排程、改以人工審閱更新資料後推送。無須額外 API 金鑰。

只要使用網站，不需要安裝 Node.js。Node.js 僅供開發與 GitHub Actions 建置使用。

排程在 UTC 10:23 更新近期公開匯率，再由**同一工作流程**發布。不要改成只推送資料後依賴另一支 push 工作流程：由內建 token 推送不會正常觸發該流程。詳見 [資料更新說明](docs/DATA.md)。若不需要更新，停用該工作流程的排程即可，網站會繼續保留現有靜態資料。

## 本機檢查正式建置

```sh
npm test
npm run build
npm run test:build
npm run preview
```

`dist/` 是可直接放上靜態主機的成品。請透過 HTTP 預覽，勿直接雙擊 `index.html` 使用 file://。正式網站沒有後台端點。

`test:build` 直接執行正式建置的匯出 Worker，涵蓋全部欄數、原算例、路線、長文字與私人行程，共 32 個情境。

## 表格格式與適用範圍

網站提供 25 份原生 XLS 空白模板：一般版與學生版各 1–12 欄的 24 組變體，加上 `student-7-private` 補充版。一般 6 欄／原學生 7 欄基準與提供的原檔相同；其他日期變體僅調整日期區的合併與原有樣式指派。

只有含私人行程的學生 7 欄表會使用補充版，將原本跨六個日期欄的 C14:M14 工作記要分開，避免公務文字出現在私人日期下方；其餘版面、字型、列高欄寬、簽章與列印設定保留。匯出修改原 XLS 容器的儲存格值與必要索引。文字放不下時，僅對可填寫欄位啟用換行或縮小字級，最低 8pt；一般版附表保留。

畫面依模板幾何繪製，不是 Excel 列印引擎。原字型未安裝時預覽會替代；下載檔仍使用原字型名稱。預覽與匯出共用文字適配結果，先換行，再按需要縮小字級。文字在最低 8pt 仍放不下時才阻擋，請精簡文字或合併相容日期；不截字、不漏日。生活費優先顯示包含結果的完整算式；窄欄改列完整金額時，完整算式補到原表備註。每筆外幣費用列出自己的匯率；必要時以費用索引指向原表備註的完整換算，不使用單據號數作索引。不要把字型替代環境的預覽視為跨電腦像素相同的保證。

第一版處理短期會議、參訪及出差。移地研究、長期駐留、檢據核實住宿等特殊例外須人工核對；一般版附表原樣保留，需要時在下載檔依證明補填。網站不自動放寬艙等、保險或雜費限制。

# 操作與介面

桌面版採左側填表、右側原表預覽。保留紙白、冷灰、墨藍與操作藍，以及思源宋體／黑體；金額採等寬數字。介面以欄位名稱、目前日期範圍與可執行動作提供指引。

## 四步驟與草稿

流程為「基本資料 → 行程與生活費 → 費用 → 檢查與下載」，可用頁籤或上一步／下一步切換，已填內容保留。初次空白表先標示必填及選填，不立即鋪滿錯誤；欄位經操作或下載檢查後才顯示相關問題。畫面主要金額為「本次申請」；有補助上限時另列計算總額及不向本案報支的差額。

「更多操作 → 查看填寫範例」另開 `?example=general` 或 `?example=student` 唯讀頁面。姓名及金額為虛構資料，不能編輯或下載；此頁不讀寫 IndexedDB，也不取代工作中的草稿。

目前草稿自動保存在瀏覽器。「重新填寫」先確認、保存目前草稿後才清空；之後可由「更多操作 → 恢復上一份草稿」復原，重新整理後仍可使用。恢復也會保留被取代的目前內容，但僅保留一份前版。保存失敗不更動目前資料，不顯示成功，並提供重試；讀取到無法辨識的舊草稿時暫停自動儲存，避免直接覆寫。

## 日期欄

起訖日期先保留為待套用內容；按「建立行程」或「套用日期」才一次更新每日資料。尚未套用時下方保留原行程，切換步驟也不丟失待套用日期。縮短日期會列出即將移除的日期與受影響費用，取消不改內容；確認後仍保留全部費用，提示核對超出新範圍的列入日期。

點選日期欄以編輯內容；按「合併日期」後才勾選合併對象，兩種操作分開。編輯區顯示目前日期範圍與同步修改的天數；上一欄／下一欄依表格欄位切換。復原合併只恢復分欄，不撤銷合併後的內容編輯。

已合併的日期共同修改，保留逐日明細。使用「拆開此欄」才拆開；更換城市遇到跨季節日支額等不相容條件時，先保留原資料並顯示原因。延長或縮短行程保留仍在範圍內的分組，新增日期可再合併。

## 地點與狀態

地點先選國家，再選該國城市；可用中文或英文搜尋。交通工具歇夜及返國日分別設定起點與迄點，日支額適用地區獨立選取，避免改動路線時誤改計算依據。

當日狀態只保留計算所需的行程類型。例假日及公差申請不另設填表步驟；匯率基準出發日集中於匯率區。私人行程仍須明確標記。

選「私人行程，不請領」後，原表工作記要固定為「個人行程」，地點為選填，整個合併欄同步修改並保存。日支額、膳宿、扣款、單據與費用欄留白。切回一般出差日保留地點，重新填寫工作記要與日支額；改為航程須重新填起訖。不同地點的私人日期不自動合併。

交通工具歇夜或返國日改為一般出差時，清除舊起迄路線及不適用的航程供餐設定。歇夜及返國日直接顯示不計住宿費；三餐勾選僅表示應扣除的免費餐食，原航程供餐不會混入。批次套用官方城市按各日期查日支額，資料尚未載入時不以來源日金額代填。

學生 7 欄且含私人日期時，工作記要按日期欄分開，避免原表共享儲存格把公務文字顯示到私人欄；仍維持主表 A4 單頁。

## 匯率與選項切換

網站提供 2025-01-02 至 2026-09-08 的 414 個臺銀報價日、19 種幣別，可另匯入官方資料或填入有依據的匯率。只套用符合所需報價日期的資料；查無資料時顯示缺漏，不自動沿用其他日期。

每筆外幣費用選臺銀來源時，會自動依匯率基準出發日查詢現金賣出；無現金報價才採即期。即使費用頁關閉，修改基準日也會更新各筆銀行匯率。缺漏平日資料不當成休市日，不自動採前一筆歷史資料；可匯入官方 CSV 或改用有依據的手動輸入。

生活費與各筆費用分別保存匯率。成功取得後收合為幣別、匯率、日期及來源摘要，需調整時展開；查無資料才提示匯入或自行填寫。自行修改或匯入的匯率不被背景查詢覆蓋，清空手動匯率也不會立即搶填。變更幣別、付款方式、來源或基準日期時，清除已不適用的數值與證明，再依新條件查詢；有效水單另依證明期間判斷，信用卡使用臺幣實付。

臺銀來源也能修改報價日期。更改日期會清除舊匯率與證明；按查詢按鈕後只讀取所選日期，不會改回預設基準日。查無資料或切換步驟、重新整理時，仍保留選定日期。日期適用性及休市證明由原有報帳檢查判斷。

匯入失敗說明實際可處理的問題，例如日期不符、下載到驗證網頁或檔案格式不符，並提供重選日期或重新下載的方式，不直接顯示解析器錯誤。更改行程起訖日期後重新核對保費上限，避免沿用舊天數的確認結果。已不適用的欄位不會因隱藏而繼續影響計算。

## 文字與預覽

長文字在原欄位內優先換行，再按需要縮小字級至最低 8pt。預覽與 XLS 使用同一適配結果，維持原表列高、欄寬及列印範圍；仍放不下時指出欄位及可調整方式，不截字。

姓名、行程與費用等欄位聚焦時標示相應表格位置。合併不可執行時直接說明缺少的選取或不相容條件；取消選取、拆開及草稿恢復均保留明確操作。

預覽預設顯示完整頁面，放大後可捲動查看。1280×800 與 1440×900 桌面保留預覽工具；窄視窗／200% 等效寬度改成單欄，用「查看報表預覽」與「返回填寫」切換。長表單操作時，步驟、申請金額與下載入口保持可取得。

## 單據與核對

費用清單顯示費類、說明、日期、原幣金額、折合臺幣與「待補資料／已填寫」，一次只展開一筆。新增費用先選費類；機票艙等、保險及適用行政費核准在相關費用內填寫。修改其他筆不會共用或取代匯率。

每筆單據號數是選填的附件自編號；尚未編號不阻擋 XLS。附件總張數可留空，原表保留「附單據__張」供後續補填，不會以費用筆數推算附件張數。需要檢附的原始憑證、票根及匯率證明仍列在應附文件。

「檢查與下載」優先列出需修正項目，提醒及計算依據可另展開。前往修改會開啟對應日期欄或費用、展開匯率等相關區塊並聚焦欄位，同時顯示文字錯誤。原表文字容量問題也計入下載前檢查。放大預覽支援 Tab、Shift+Tab、Escape 與關閉後還原焦點；窄桌面／200% 等效寬度保留草稿狀態與操作。

## 維護

專案已使用 `npx impeccable install` 安裝 `.github/skills/impeccable` 的設計指引。後續修改應延續既有桌面操作與中性欄位用語，並驗證鍵盤操作、原生勾選框、國家／城市選取、日期欄同步修改與原表預覽。設計工具不隨網站執行，不新增後台或使用者資料傳輸。

## 原表匯率與生活費結果

總計旁明確標示「生活費美元匯率」。每筆外幣費用使用自己的匯率；同幣別不同匯率仍分筆。完整換算較長時先保留原幣金額乘匯率，必要時以 `[費用順序]` 對照原表備註的日期、費類與完整換算；索引不要求單據號數。

生活費優先顯示完整算式與結果，不能只保留等號前的算式。一般版極窄欄改列完整美元金額時，完整算式補到原表備註。若備註或費用仍超量，指出需調整的位置，不截字。

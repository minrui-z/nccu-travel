# 學生補助上限與超額不報支

查核日期：2026-09-09。學生身分本身沒有全校所有案件共用的補助上限；應採本案核定函金額、可報費目及適用補助辦法。網站不依地區或學生身分自動代填上限。

[國科會補助國內研究生出席國際學術會議作業要點](https://law.nstc.gov.tw/LawContent.aspx?id=FL038260) 第六點規定在核定經費限額內依規定費目報支；第八點要求有分攤時列明全部經費內容及各來源補助項目與金額。

[政大學術研究補助辦法（115年4月23日）](https://ord.nccu.edu.tw/upfiles/獎勵補助/學生/國立政治大學學術研究補助辦法115.04.23.pdf) 另有該補助方案的地區額度與調整條件，不能當作所有學生案件的共同上限。[政大115年檢查表](https://acc.nccu.edu.tw/sites/default/files/國立政治大學國外出差旅費報支重點檢查表%28115年版%29.pdf) 要求按日填列及經費分攤文件。

## 網站填表方式

例如旅費計算額為 77,759 元、本案核定上限為 70,000 元，且超額自行負擔：

- 原表上方金額填 70,000。
- 每日明細保留計算內容；總計同時保留 77,759 與申請 70,000。
- 備註說明本案上限、超額 7,759 不向本案報支並自行負擔。
- 勾選其他來源分攤時，說明改為另依分攤表辦理，不自動稱為自付。

不把補助不足的差額填入「第九點扣除項目金額」，該列仍只處理生活費應扣項目。也不將日支額計算結果稱為實際支出。核定費目有特別限制時，應按核定項目填報並附分攤資料，不能只靠總額上限判斷。

上述上方金額、總計與備註的對應，是網站採用的透明填表方式；所查官方資料沒有指定超額自付必須使用這套固定欄位句型。若承辦提供個案填法，依其要求調整備註及申請資料。

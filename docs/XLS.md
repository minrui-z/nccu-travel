# 原格式 XLS 匯出與維護

匯出器修改 BIFF8／OLE 二進位檔，副檔名與檔案內容均為原生 XLS。使用者不需要 Java、Excel、LibreOffice 或後台服務。

## 發布的模板

`public/templates` 包含一般版與學生版各 1–12 區段的 24 組變體，以及 `student-7-private` 補充版，共 25 份原生 XLS 與 JSON 描述。一般 6 區段、原學生 7 區段分別與提供的空白原檔完全相同；其餘日期變體預先調整日期區的合併範圍及儲存格樣式指派。日常建置直接使用已驗證變體，不重建模板。

原學生 7 欄模板的 C14:M14 工作記要由六個日期欄共享。只有學生表為 7 欄且含私人行程時，才選用補充版，將該工作列按既有日期欄分開並使用原有樣式，避免公務文字跨入私人日期欄。補充版不改原檔，亦不改其他合併、字型與樣式定義、列高欄寬、簽章或列印設定。

JSON 記錄模板 SHA-256、允許填寫的儲存格、日期區段、原表合併、字型、列高欄寬及繪圖資料。下載前核對模板雜湊，檔案與描述不一致就停止。

## 匯出流程

1. 畫面與 Worker 共用 `lib/claim` 精確十進位計算；Worker 再次檢查資料及日期區段。
2. `claim-mapping.ts` 將資料對應至原表欄位，保留原有艙等問題、簽章與附註。`text-fitting.ts` 在固定儲存格範圍內嘗試換行與字級調整，再檢查文字容量。
3. `xls-exporter.ts` 以 `cfb` 讀取 OLE 容器，修改允許的值、共用字串及必要索引。需要調整文字時，新增原 FONT／XF 記錄的副本，僅改字級、換行及相關文字適配設定，再將可填寫儲存格指向新增樣式；原有 FONT／XF 定義及其編號不改寫。支援中文字串、富文字、空白、零值、數值與跨 SST CONTINUE 記錄。
4. 原字型名稱、既有字型與樣式定義、框線、列高欄寬、圖形、其他 OLE 串流及列印設定保留。新增樣式只供可填寫欄位使用；主表維持單頁，一般版原附表另佔一頁。
5. Worker 回傳二進位資料，瀏覽器在本機下載 XLS。

只接受專案內已驗證的模板，不提供任意上傳 XLS 的修改功能。`readOriginalText` 僅供讀取原始模板，不能用來驗證已修改輸出；輸出應另以獨立讀取器查核。

窄欄的自動生活費文字先保留完整式，容量不足時改為等義簡式或扣餐前生活費金額；免費餐食扣除仍在第 23 列另列，避免重複扣餐。「無免費供餐」在學生版窄欄可等義顯示為「無免費餐」。完整逐日算式保留在核對頁；使用者輸入文字不自動縮寫。自動簡式不改變金額。可填寫欄位的文字適配可另行調整換行及字級，欄寬與列高不變。

私人日期欄寫月份、日期、固定工作記要「個人行程」及選填地點；生活費、各費目、扣除額及單據號數均為 BIFF `BLANK`。即使舊草稿曾有請領資料，也不寫入零值、公式、「無免費供餐」或殘留金額。整欄合併的私人日期同樣處理；切回出差日保留地點，須重新填工作記要與日支額。

## 正式 Worker 的 CFB 相容處理

`cfb@1.2.2` 的 CommonJS 匯出尾段還會檢查全域 `require`。Vite 正式 Worker 沒有這個全域物件，曾造成開發版正常、正式版無法匯出的問題。

`build/cfb-browser.ts` 只在建置前移除該段過時的 `require` 條件，不修改 XLS 解析或序列化內容；同時套用於主程式與 Worker。版本固定為 1.2.2，若上游尾段改變，建置會明確失敗。

`npm run test:build` 直接執行實際建置出的 Worker，不提供 `require`、`Buffer` 或其他 Node 全域，驗證兩版 77,759 元範例及全部 24 種欄數，加兩版起迄、長文字及私人行程範例，共 32 個實際匯出情境；私人學生 7 欄情境使用補充模板。升級 Vite 或 CFB 後必須保留此項測試。

## 變更模板前的驗證

現有 25 份模板就是發布資產。若官方改版，請以新的空白檔重新準備所有區段變體、私人學生 7 欄補充版與描述，不可只覆蓋某個 XLS 或沿用舊雜湊。準備工作可在開發環境離線完成；網站使用及日常建置不需要模板產生服務。

執行 `npm test`、`npm run build`、`npm run test:build`，再依 [QA 操作](../qa/README.md) 使用獨立 xlrd 讀取及同一字型環境列印所有變體。檢查非修改資料、原字型、框線、簽章文字框、列印範圍與附表。

文字容量依原表幾何與原字型度量做保守估算。適配優先保留原字級並換行，必要時縮小至可容納的字級，最低 8pt；富文字保留各段字型名稱，字級按原比例縮小並以 8pt 為下限。超出最低可讀字級容量時阻擋匯出，不截字、不漏日。網頁預覽使用同一份適配後描述與文字，下載則寫入對應 FONT／XF 記錄。網頁預覽與 LibreOffice 檢查不等同 Excel 的像素比對；正式送件仍應在安裝模板字型的 Excel 環境確認字型與列印預覽。若發現差異，修正模板或匯出器並重驗，不以 HTML 或 XLSX 取代。

技術來源：[js-cfb](https://github.com/SheetJS/js-cfb)、[Microsoft XLS 格式規格](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-xls/)、[Vite 相對路徑](https://vite.dev/guide/build.html#relative-base)。

## 日期欄擴充

兩個原檔日期區均為 C:N，共 12 個底層欄。新增日期欄只調整 C11:N24 的合併與既有樣式指派；字型與樣式定義、整欄寬、列高、列印範圍、簽章與一般附表不變。差異清單為 `qa/template-style-differences.json`。這些是空白模板的差異；填入長文字後的匯出可再新增前述文字適配樣式。12 欄仍受單頁範圍與最低 8pt 字級的文字容量限制。

既有一般 6 欄及學生 7 欄為原空白檔基準。`scripts/build-expanded.ts` 與 `scripts/extract-manifests.py` 可重建新增變體；日常建置不執行此步驟。

完成一般變體及描述後，執行下列指令另行產生私人學生 7 欄補充版；此腳本不覆蓋 `student-7.xls` 或 `student-7.json`：

```sh
node --import tsx scripts/build-student-private-template.ts
```

`tests/student-private-template.test.ts` 驗證可重現的輸出、原基準雜湊、工作列以外的儲存格與記錄，以及原字型、樣式定義和版面保留。私人費用格的空白結果另由匯出測試覆蓋；獨立讀取與列印仍依 QA 流程執行，不據此宣稱跨軟體像素完全相同。

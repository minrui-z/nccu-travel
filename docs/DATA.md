# 公開資料與更新操作

本網站使用政治大學及行政院主計總處公開規則、官方日支額及臺灣銀行歷史匯率。資料檔和網站一起發布至 GitHub Pages，使用網站時不需後台伺服器，也不會把 CSV、報帳內容或個人草稿送給資料提供單位。

## 先確認資料適用日期

日支額及規則檔採 **115 年 1 月 1 日（2026-01-01）生效的新制**，用於短期會議、參訪及一般出差。沒有提供 2025 舊制、移地研究、長期駐留或其他特殊補助計算。不要把新制日支額與匯率規則倒套到舊案件。

保費表另有契約期間，與日支額的版本不同。請依實際保單確認適用契約、一般險或申根險、年齡方案及保險天數；不能只用出發日期或公差天數代替保單資料。

「資料擷取時間」代表何時讀取來源，「報價日期」代表匯率適用哪一天，兩者不同。網站下載了最新資料，也不表示舊日期都已收齊。

## 網站使用者：查匯率與日支額

1. 填入實際出發及返國日期，依當地日期建立逐日行程；在匯率區另填「匯率基準出發日」。匯率基準採奉派出差起日，不因提前私人出國而改變。
2. 選擇目的地後，網站依該日季節套用美元日支額。有的城市部分季節採該國「其他」，來源旁會說明。手動改數額時，另留存官方依據。
3. 有有效美元結匯證明時，選擇結匯憑證；日期須在奉派出差前 15 日至實際返國日之間，兩端均包含。
4. 沒有結匯證明時，生活費使用奉派日前一日的臺銀 **美元、現金、賣出** 匯率。假日往前，但缺少網站快照不代表銀行休市。
5. 使用臺銀來源且尚未填匯率時，網站自動查詢對應日期；成功後顯示匯率、日期及來源摘要，可展開修改。如果所需日期沒有有效快照，請取得官方 CSV 或依有效官方證明手動輸入。網站不應擅自用較舊匯率填補資料缺口；手動修改及匯入內容也不被背景查詢覆蓋。
6. 每筆檢據費用可有自己的幣別與匯率；不能因生活費已填美元匯率，就把歐元、日圓等費用當成美元。信用卡費用可填實際結算臺幣及該筆交易手續費，避免重複換算。

手動輸入仍分兩種日期依據：

- **銀行報價**：適用奉派出差前一日規則。若使用更早日期，須有中間未報價日的官方依據。基準日尚未到來，不能以最近匯率代替。
- **結匯憑證**：適用奉派前 15 日至返國日的證明期間，並記錄水單或匯率證明。

檢據外幣費用只有在該幣別沒有臺銀現金賣出時才改用即期賣出；兩者都沒有時，再依規定使用發行國央行／貨幣主管機關的對美元匯價折算。這種換算須保留方向及來源證明。

## 如何取得臺銀官方 CSV

1. 開啟 [臺灣銀行歷史匯率查詢](https://rate.bot.com.tw/xrt/history?Lang=zh-TW)。
2. 選擇所需日期的「本行營業時間牌告匯率／收盤匯率」資料，先確認頁面列出的實際報價日期。
3. 使用頁面的「下載 Excel（CSV）檔」，保留原始檔案與原檔名。官方檔名通常含 `ExchangeRate@YYYYMMDD...` 報價時間。
4. 回網站先填寫報價日期、勾選已核對日期，再選擇官方 CSV。網站檢查檔名日期與指定日期是否一致，生活費使用美元現金賣出欄；檢據費用依該筆幣別使用現金賣出，缺少時才改採即期賣出。
5. 若原檔名已被改名、不含日期，必須先從官方下載頁或其他證明核對日期，填入日期並確認日期依據，才能匯入。系統將這種資料視為使用者提供的日期證據，不會聲稱已由自動下載驗證。

請保留原始 CSV；用試算表另存、改表頭、只留下美元一列或調整小數，可能使格式查核失敗。官方缺少的匯率欄可能顯示 `-` 或 `0.00000`，在網站中代表「沒有報價」，不是零元匯率。

若匯入失敗：

| 顯示情況 | 處理方式 |
|---|---|
| 檔案是 HTML 或驗證頁 | 重新從臺銀可正常顯示的正式查詢頁下載 CSV；不要把驗證頁改副檔名。 |
| 報價日期不同 | 核對查詢日期、檔名及網站填入日期，不能把另一日資料當作所需日期。 |
| 檔名缺少日期 | 提供官方日期依據並明確確認，或重新下載保留原檔名。 |
| 幣別不足、表頭或金額格式不符 | 使用未修改的完整官方 CSV。 |
| 所需日期沒有報價 | 查核銀行實際休市情況；缺網站資料本身不是休市證明。 |

## 生活費、進位與匯出狀態

返國日及在交通工具上歇夜的住宿部分只扣一次，生活費至多保留 30%。私人行程不支領生活費；費用列支日也必須屬於可列報公差。費用的列支日與實際付款日不同，預先付費不應被塞進私人行程。

供餐扣減除了免費餐食，也包括報名等費用已附帶的餐食，以及符合規定的檢據住宿所附餐食。飛機航程供餐免扣。一般自行住宿方案的早餐，不能一律當成第八點特殊檢據住宿供餐。

**尾數口徑仍是待核對項目。** 官方日支表要求百分率計算總計後不足一元進位，但目前未取得足以確定幣別及換匯順序的校內說明。依使用者同意，第一版暫採：逐筆保持十進位精度，同費目精確加總臺幣後四捨五入至元，再加總各費目。合併或拆開日期欄不改變總額。

原範例生活費 `268 × 3.44 × 29.995 = 27652.9904 → 27653`，同時符合臺幣向上進位及四捨五入；報名費 `350 × 29.995 = 10498.25 → 10498`。範例不能單獨證明每種費目、多筆同費目都應採目前口徑，2026-09-09 依使用者要求移除介面與檔名的狀態標記；這不代表官方已確認所有取整情況。

## 維護者：資料檔案

| 檔案 | 內容 |
|---|---|
| `public/data/rules-115.json` | 規則摘要、生效日期、官方條款／頁碼及已確認或待確認狀態。 |
| `public/data/allowances-2026.json` | 551 筆國外及 19 筆陸港澳目的地，含全部季節。 |

| `public/data/source-manifest.json` | 已審閱官方 PDF 的 URL、擷取時間及 SHA-256。 |
| `public/data/fx/index.json` | 現有報價日期、日期總數、幣別、各快照檔案與雜湊；不代表完整營業日日曆。 |
| `public/data/fx/YYYY-MM-DD.json` | 單一報價日各幣別的現金／即期買入與賣出。 |
| `public/data/sources/` | 官方原始 PDF、驗證後的臺銀原始 CSV及查核樣本。 |

日支額中的 `isCountryWide` 是官方對全國／地區統一定額；`isCountryOther` 才是「其他」。`countryOtherId` 可能為空，不可自行建立 Other 金額。

季節用 `MM-DD` 表示，起訖都包含；起日大於迄日表示跨年。同價但不連續的期間分成多筆。杜拜的 8–9 月及 San Sebastian 的 11–3 月按官方同國 Other；不能把前一季費率延用。

保費兩個契約期間為 2025-06-21–2026-06-20、2026-06-21–2027-06-20。目前政大兩份附件的檔案內容相同，但仍各保留來源與期間。期間證據來自政大附件檔名，內頁未印期間；成人方案未印保額，`statedCoverageNtd` 因此為空。報支保額上限 400 萬與共同契約保費上限是兩項獨立限制。

## 維護者：本機更新

Node 更新程式無額外套件依賴，建議 Node 24。在網站專案目錄執行：

```sh
node --test tests/public-data.test.mjs tests/fx-history.test.mjs
node scripts/update-fx.mjs --date 2026-01-05
node scripts/update-fx.mjs --days 7
```

預設更新截至臺北昨天的 7 個曆日，包含重新查詢已收錄日期。補抓歷史資料可直接指定起迄日；省略 `--end` 時，以臺北昨天為迄日：

```sh
node scripts/update-fx.mjs --start 2025-01-01 --end 2026-09-08 --concurrency 3 --delay-ms 500
node scripts/update-fx.mjs --start 2026-01-01
```

`--start` 區間模式預設略過已驗證快取：會核對已保存官方 CSV 的 SHA-256、快照日期、來源與各幣別匯率，全部一致才免去重複下載。加 `--refresh-existing` 可重新取得已有日期；其他模式可加 `--skip-cached` 啟用相同的快取檢查。`--date`、`--start` 與 `--days` 擇一使用，單次區間最多 3,660 個曆日。

預設逐一請求，最多可設為 3 個並行請求；`--delay-ms` 設定每個並行流程的請求間隔。暫時性來源錯誤會有限次重試；遇驗證頁、拒絕存取或重試後仍被限流，會停止其餘請求，保留已驗證資料。

程式只接受臺北今日以前的收盤日期。它使用 Node 原生 `fetch` 普通 HTTPS GET，沒有代理、網站 cookies、秘密 API 憑證或驗證頁破解；已在本機成功下載真實官方 CSV。**尚未在正式 GitHub runner 驗證，不能保證來源網站對所有環境或所有日期都可下載。**

每次下載會驗證回應格式、買賣欄位、幣別、非負有效數字與官方下載檔名的報價日期。HTML 即使回傳 HTTP 200 也會拒絕；日期不同、沒有日期或資料不足也不發布。先保存驗證過的原始資料，再寫入快照；失敗保留原快照。所有日期皆失敗時回傳非零結束碼，部分日期失敗則逐筆列出。

2026-09-09 已收錄 **414 個報價日、每個日期 19 種幣別**，實際報價範圍為 **2025-01-02 至 2026-09-08**（2025 年 246 日、2026 年 168 日）。每份快照均保留官方原始 CSV、來源網址、取得時間與 SHA-256，已逐份核對原始檔雜湊及解析內容。後續日期總數、範圍與幣別以 `fx/index.json` 為準。

本次檢查 2025-01-01 至 2026-09-08 的 616 個曆日；其中 202 個日期因官方回應缺少可驗證的報價日期而未收錄。**缺漏或下載失敗不等於銀行休市**，也不代表可以自動套用前一個已收錄日期。要確認某段歷史完整性，仍須另核對實際未報價日；下載更多歷史匯率不會把本網站的 115 年規則變成適用舊制案件。

19 種幣別為 AUD、CAD、CHF、CNY、EUR、GBP、HKD、IDR、JPY、KRW、MYR、NZD、PHP、SEK、SGD、THB、USD、VND、ZAR。原始資料未提供的現金或即期欄位仍保留為無報價，不補零、不自行推算；實際使用的賣出種類仍依前述規則判定。

## 維護者：GitHub Actions 與排程恢復

`.github/workflows/pages.yml` 已整合資料更新、網站建置與 GitHub Pages 部署。只需 GitHub 內建短效 `GITHUB_TOKEN`；不要加入臺銀登入資訊或個人秘密憑證。

排程更新應保留驗證後的歷史快照，不能每次部署只帶最近幾天、丟掉舊資料。若使用 `GITHUB_TOKEN` 把快照提交回儲存庫，該推送通常不會再觸發另一支 push 工作流程，所以應在同一次執行完成建置與部署，或明確呼叫可重用的部署流程。

手動執行或恢復排程：

1. 在 GitHub 儲存庫開啟 **Actions**，找到 **Build and publish GitHub Pages** 工作流程。
2. 若因長期未使用而顯示停用，先選擇重新啟用工作流程；公開儲存庫排程可能因 60 日無活動而停用。
3. 若是 fork，先依 GitHub 畫面啟用 Actions／對應工作流程。不要假設 fork 後排程會自動執行。
4. 使用 **Run workflow** 手動執行，勾選 **update_rates**。單日更新填 **quotation_date**；整段歷史補抓填 **history_start**，從該日起補到臺北昨天並略過已驗證快取。兩者均使用 YYYY-MM-DD、須早於臺北今日，且互斥，不能同時填寫；同時填寫會讓更新步驟失敗並保留現有資料。兩欄留白則更新截至臺北昨天的 7 個曆日。只發布、不更新資料時取消勾選 update_rates。
5. 查看每日期更新結果，確認新增 CSV 與 JSON 日期吻合，再確認網站部署成功。排程延遲或暫停時，網站仍應呈現舊資料的報價日期及缺漏提示。

正式環境驗收至少包含：一次正常下載、一次指定日期下載、來源拒絕時保留舊資料、發布後網站能讀到新快照、缺少平日資料時不套用更早報價。來源端回傳驗證頁時，保留手動官方 CSV／憑證途徑，不以代理或驗證繞過方式維持更新。

## 維護者：規則與 PDF 改版

先檢查已審閱的官方來源是否改變：

```sh
node scripts/check-reference-sources.mjs
```

此工具只比較官方 PDF 位元組與已記錄雜湊。網址內容變動或下載失敗時會保留目前版本，不會擅自覆蓋已審閱資料。它無法保證發現新公告的新網址，維護時也須查看主計總處及政大最新公告。

新版本須另確認生效日與過渡規定，保留舊版本供舊案件使用。不能只換數字而沿用舊生效日期；新增季節必須驗證跨年、日期端點、缺漏季節的 Other 及全國定額項目。

PDF 重新產生／核對 JSON：

```sh
python3 -m venv .venv-data
.venv-data/bin/python -m pip install -r requirements-data.txt
.venv-data/bin/python scripts/build-reference-data.py --output-dir .reference-data-review
.venv-data/bin/python scripts/verify-reference-data.py --json-dir .reference-data-review
```

確認差異後才將審查目錄內的三個 JSON 複製到 public/data。腳本限定目前已審閱的 PDF，不能直接套用未知新版；不下載來源或自動確認規則。

在 macOS Codex 執行前，先載入工作區依賴並使用 bundled Python；不要使用系統 LibreOffice 開啟或轉檔。生成器使用 `pypdf`，獨立驗證器使用 `pdfplumber` 格線抽取，逐筆比對城市、季節、金額、全部保費與來源雜湊。不要只用同一段解析程式產生的結果測自己。

官方確認尾數口徑後，需同時更新規則狀態、計算引擎、匯出說明與測試。至少測生活費美元／臺幣進位位置、多筆同費目、不同匯率、信用卡手續費及日期分組前後的總額一致性。

## 交通工具歇夜的地點

起迄地點與生活費適用地區各自填寫。[115年檢查表](https://acc.nccu.edu.tw/sites/default/files/國立政治大學國外出差旅費報支重點檢查表%28115年版%29.pdf) 第4頁規定交通工具歇夜扣除住宿70%。[政大提供的解釋彙編](https://acc.nccu.edu.tw/sites/default/files/travel10704.pdf) PDF第18頁／印刷第15頁對回程歇夜及返國日以班機起飛地區作說明。

目前未取得足以直接把所有去程、中轉情況自動對應單一城市的115年通則，網站不因改選迄點就推定日支額地區。使用者另選適用地區，查表仍遵守原生效日期與季節條件。臺灣地點只有路線選項，絕不新增或推算美元日支額。
